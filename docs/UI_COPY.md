# Тексты интерфейса

Правило для новых экранов, API-сообщений и диагностических отчётов: **факт → влияние → действие**. Ненужные части опускаются.

- Факт подтверждается ответом API или измерением. При отсутствии наблюдений показываем «Нет данных».
- Сменившийся DHCP-сервер не устанавливает причину события. Не делаем выводов об оплате, аварии или разрыве всех соединений без измерений.
- Возможное последствие обозначаем явно: «Возможен разрыв внешних соединений».
- Не используем разговор от имени автора, риторические вопросы, спор с воображаемым собеседником и вводные фразы вроде «на самом деле».
- Действие ведёт к конкретному месту. Название раздела берётся из реестра навигации; в предупреждении нужен кликабельный переход с полным путём.
- «Общие правила» — исключения перед профилями (кроме аварийного «Всё напрямую»). «Правила профиля» — правила внутри выбранного профиля. Сброс профиля не удаляет общие правила.
- «Изменён» означает отличие сохранённых настроек от стандартных или исходной копии. Несохранённый черновик — отдельный статус.
- Каждый новый русский текст получает английский перевод; динамический текст — шаблон перевода.

При проверке интерфейса просматривать и статические подписи, и сообщения, которые возвращает API. Проверять смысл, источник факта, путь действия, обе темы, русский и английский языки.
